# Requisitos do Sistema

## Objetivo

O sistema tem como objetivo apresentar os produtos e serviços oferecidos por uma pequena lanchonete.

## Funcionalidades

O sistema deverá permitir:

- Visualização dos produtos.
- Visualização dos pedidos.
- Acesso à página de contato.
- Apresentação das informações da lanchonete.

## Usuários

O sistema será utilizado pelos clientes da lanchonete para consultar os produtos e informações disponíveis.
