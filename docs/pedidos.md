# Pedidos

## Sobre os Pedidos

A funcionalidade de pedidos permite que o cliente informe o produto desejado e a quantidade.

## Informações do Pedido

O pedido deverá conter:

- Produto escolhido.
- Quantidade.
- Envio do pedido.

## Funcionamento

O cliente poderá informar o produto desejado, indicar a quantidade e enviar o pedido por meio do formulário disponibilizado na página de pedidos.

Esta funcionalidade representa uma versão inicial do sistema.
